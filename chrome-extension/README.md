# Shoppingday 네이버쇼핑 순위 관측 확장 프로그램

성장상품관리에서 사용자가 요청할 때 실제 Chrome 탭을 열어 네이버쇼핑 가격비교 PC
자연검색 결과를 최대 100위까지 확인한다. 예약 조회, CAPTCHA 해결, IP 변경 또는 차단
우회 기능은 포함하지 않는다.

## 로컬 설치

1. Chrome에서 `chrome://extensions`를 연다.
2. 오른쪽 위 `개발자 모드`를 켠다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누른다.
4. 저장소의 `chrome-extension` 폴더를 선택한다.
5. Shoppingday 성장상품관리 페이지를 새로고침한다.

코드를 변경한 뒤에는 확장 프로그램 화면에서 새로고침 버튼을 누르고 Shoppingday
페이지도 다시 불러온다.

## 관측 범위

- PC `search.shopping.naver.com`의 기본 검색 결과만 확인한다.
- `광고` 표시가 있는 상품 카드는 순위에서 제외한다.
- 상품 카드 URL과 속성에서 채널 상품번호 또는 스마트스토어 상품 경로를 찾아
  대상 상품을 식별한다.
- 결과에는 PC, 확인 시각, 확인 범위와 발견·미노출·차단·실패 상태를 저장한다.
- 네이버 공식 순위 API 값이 아니라 조회 시점의 공개 화면 관측값이다.

Chrome 확장 프로그램만으로 실제 모바일 Chrome과 동일한 사용자 에이전트·화면을
보장할 수 없으므로 모바일 조회는 이 버전에 포함하지 않는다.

## 직감 위탁상품 품절·단종 확인

성장상품관리 `상품 운영`에서 `zicgam.com/product/detail.html?product_no=...` 형식의
공급처 URL을 입력하면 로그인된 Chrome 탭으로 상품을 연다. 직감은 비로그인 상태에서
승인회원 로그인 페이지로 이동하므로 Chrome에서 먼저 직감 승인 계정으로 로그인해야
한다.

## 직감 전체 상품 가져오기

확장 프로그램 0.4.0부터 Shoppingday의 `위탁상품 가져오기` 화면에서 직감 전체
카탈로그 수집을 시작할 수 있다. 로그인된 직감 탭이 카테고리와 목록 페이지를 먼저
순회한 뒤 상품 상세를 한 건씩 확인한다. Shoppingday API가 상품 한 건을 저장한 뒤에만
다음 상품으로 이동하며, 신규 상품은 추가하고 기존 상품은 공급처 원본 스냅샷만
갱신한다.

- 작업 중에는 Shoppingday 탭과 직감 작업 탭을 닫지 않는다.
- 상품 수에 따라 수 시간이 걸릴 수 있으며 `중단` 후 다시 실행할 수 있다.
- `product_no`로 중복을 제거하므로 다시 실행해도 같은 상품을 중복 생성하지 않는다.
- 수집된 상품은 스마트스토어에 자동 발행되지 않는다.
- 직감 화면 구조가 바뀌어 상품을 찾지 못하면 목록·상세 선택자를 실제 로그인 화면에
  맞춰 갱신해야 한다.

확장 프로그램은 판매 가능, 일부 옵션 품절, 전체 품절, 명시적 단종·판매 종료,
로그인·회원 승인 필요, 판정 불가와 확인 실패를 구분한다. 판정 결과는 확인 문구와
옵션 목록, 확인 시각을 함께 저장하며 스마트스토어 상품을 자동으로 품절 처리하지
않는다.

성장상품 목록의 `직감 전체 확인`은 저장된 직감 상품 URL을 한 탭에서 순차 확인한다.
상품별 결과를 즉시 저장하므로 중간에 중단되어도 완료된 상품은 유지된다. 전체 확인
중에는 Chrome과 Shoppingday 관리 화면을 닫지 않는다. 개별 확인은 기존처럼 상품
상세의 `Chrome으로 품절·단종 확인` 버튼을 사용한다.
