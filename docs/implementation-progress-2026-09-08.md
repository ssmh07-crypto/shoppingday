이 문서는 완료 선언이 아니라 검증·인수인계 기록이다.

## 2026-09-09 후속 상태 (아래 과거 기록보다 우선)

일괄 키워드 실패 복구와 미리보기·스타일, GitHub Actions 대량 등록 실행 및 실패 상품 재처리,
성장관리 정밀 분석 공통 화면과 저장·추천 초안 연결, 공급 상태 수동 반영 및 원본 상세페이지
비교·적용을 추가했다. `NEXT_SESSION.md`의 2026-09-09 절에 기능과 제한을 상세 기록했다.
DB 0035까지 총 36개 적용. 사용자 승인 후 GitHub 릴레이 Secrets 두 항목 등록 완료.
전체 434개 테스트, 타입 검사·lint·운영 빌드·번들 검사 통과. 실제 브라우저와 실계정 E2E는
아직 남아 있으며 무인 품절/단종/상세 자동 반영은 활성화하지 않았다.

## 이번 작업에서 추가한 기능

- 선택 도매처 일괄 실행, 마지막 선택, 실패 항목 재실행, 개별 실행 잠금.
- Chrome 0.5.19 로그인 보관함: 로컬 암호화, 세션 잠금 해제, 로그인 양식 검증, 추가 인증 시 수동 처리.
- 공급가 변경 시 기존 판매가/공급가 비율로 판매가 재계산(10원 올림). 0원·누락·통화 불일치는 계산하지 않음.
- 공급처 원본 및 판매가 변경 감사 이력, 변경 전후 조회 화면.
- 등록 상품의 가격 반영 대기열과 수동 순차 반영, 실패 재시도, 최신 판매가 변경 시 오래된 작업 폐기.
- 네이버 가격만 변경하는 API와 서명된 릴레이 경로. 반영 후 실제 채널 상품의 원상품번호·판매가를 검증.
- 친구도매 예약에 가격 자동 반영 옵션(기본 꺼짐). 도매처·소유자 범위를 제한하고 매 상품 처리 전 예약 해제 여부 재확인.
- 같은 상품군의 선택 상품에 저장된 엑셀 후보 재사용, 카테고리·태그 선택 적용, 미리보기와 버전 충돌 방지.
- 명시된 단종과 품절 구분. 조회 실패는 단종으로 확정하지 않음. 편집 화면의 미확인 상태를 판매 가능으로 표시하던 오류 수정.

- `0033_solid_thunderball.sql`: 공급처 단종 상태 추가.
- `0034_slow_mandroid.sql`: 예약 가격 반영 옵션(기본 false).
- 위 세 마이그레이션은 연결된 DB에 적용 완료. 기존 상품 삭제나 실제 네이버 가격 수정은 실행하지 않음.
- 읽기 전용 검증 결과: 적용 마이그레이션 35개, 가격 대기열 RLS 켜짐, 가격 작업·활성 예약·자동 가격 예약 각 0개.

## 아직 필요한 작업 / 제한

- 실제 로그인 및 수집 E2E: 사용자 Chrome 확장 업데이트·보관함 설정 필요.
- 제공된 브라우저 연결은 기존 런타임에서 가용 브라우저 없음, 갱신 런타임에서 신뢰된 브라우저 서비스 부재로 실패. UI 시각 검수 미실행.
- GitHub Actions에는 네이버 릴레이 URL/인증키 Secret이 아직 없음. 기존 연결값 등록 허용을 사용자에게 질문한 상태. 예약 가격 반영은 이 설정과 PC 릴레이 실행이 필요함.
- 직감·이불삼촌은 열린 Chrome·가져오기 화면에서 동작하는 6/12/24시간 예약 추가. 기본 꺼짐, 저장한 도매처만 실행, Web Locks로 같은 브라우저의 중복 실행 방지. PC 종료·잠자기·탭 제한 시 실행 지연을 안내함.
- 품절/단종/상세 변경은 이력 확인 후 기존 상품 편집·네이버 반영 경로 이용. 항목별 자동 반영 대기열은 가격만 구현.
- 성장관리에서 연결된 상품의 공통 편집 작업공간(엑셀·키워드·카테고리·속성)을 새 탭으로 열도록 연결. 소싱 정밀 분류 UI 완전 공통화, 새 일괄 가공 경로의 추가 통합 테스트, 브라우저 종료 후 대량 등록 실행 개선은 남아 있음.
- 이번 변경의 커밋·푸시·운영 배포는 후속 기록으로 확인할 것.

## 참고

- 가격만 변경하는 요청은 [네이버 멀티 상품 변경 API](https://apicenter.commerce.naver.com/docs/commerce-api/current/update-multi-products-product)의 `SALE_PRICE`와 최종 `salePrice`를 사용한다. 상품명·태그를 함께 수정하지 않는다.
- 마진은 수수료·배송비를 포함한 순마진이 아닌 공급가/판매가 비율이다.
