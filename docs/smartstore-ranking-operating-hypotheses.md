# 스마트스토어 순위 운영 가설

마지막 갱신: 2026-07-30

이 문서는 사용자가 실제 스마트스토어 운영에 적용할 전략을 Shoppingday가 일관되게
기억하기 위한 기준이다. 네이버가 공개한 고정 배점표나 노출 보장 공식이 아니라
`사용자 운영 가설`이다. 화면에서도 실제 검색량·실제 순위와 구분해 표시한다.

## 적용할 운영 가설

1. 가격비교 검색의 공통 구조는 `적합도 × 인기도 × 신뢰도`로 이해한다.
   N+스토어는 여기에 사용자별 `선호도`가 추가되는 별도 지면으로 구분한다.
2. 적합도에 영향을 주는 필드의 힘은 `상품명 > 스토어명 > 카테고리 > 속성 > 태그`
   순서로 가정한다.
3. 자연검색 1페이지는 40개 상품으로 가정한다.
4. 같은 시각의 동일 순위 가정은 가격비교 지면을 표본 조사할 때만 제한적으로 사용한다.
   N+스토어는 성별·연령·클릭·구매 이력에 따른 개인화 결과이므로 동일 순위를
   가정하지 않는다.
5. 월간 검색량 1,000 이하 키워드를 신규 판매자의 초기 공략 후보로 표시한다.
6. 소싱 등록 상품명은 검색수 1,000 이하의 관련 후보 전체를 자동 연결 여부와 실제
   검색수로 보여주고, 사용자가 추천에 사용할 후보를 여러 개 확인·선택해 조합한다.
   문자열 연결에 실패한 후보도 사용자가 같은 상품형임을 확인하면 사용할 수 있으며,
   서로 다른 검색 상품형을 가능한 범위에서 함께 검토하고 최종 50자로 제한한다.
   50자는 네이버 공식 배점이나 제한이 아니라 빠른
   검토를 위한 사용자 운영 기준이다. 스마트스토어 공식 SEO 가이드(2025년 3월판)는 50자 상품명을
   `지나치게 긴 상품명` 위반 사례로 제시하지만 일률적인 API 상한으로 명시하지 않는다.

## 스마트스토어 공식 SEO 가이드에서 확인한 사실

- 가격비교와 N+스토어 공통 요소는 적합도·인기도·신뢰도이며 N+스토어에는 선호도가
  추가된다.
- 최근 1개월의 클릭·리뷰·판매지수·최신성이 인기도 설명에 사용된다.
- N+스토어는 사용자 특성과 쇼핑 이력에 따라 개인화된 결과를 제공한다.
- 상품 삭제·재등록 반복과 클릭·구매·리뷰 조작은 인기도 손실 또는 제재 위험이 있다.

위 항목은 스마트스토어가 공식 제공한 `검색SEO가이드_202503.pdf`의 설명을 요약한
것이며 고정 배점이나 노출 보장식으로 환산하지 않는다.

## 구현 원칙

- 검색량 1,000 이하라는 이유만으로 상품과 무관한 키워드를 추천하지 않는다.
- 검색량 순으로 의미가 겹치는 키워드를 반복 배치하지 않고, 서로 다른 상품 특징을
  설명하는 후보를 우선한다.
- 가격비교는 인기도·적합도·신뢰도 입력값이 모두 실제로 확보된 경우에만 가설 점수를
  계산한다. N+스토어는 선호도까지 실제로 확보되지 않으면 점수를 계산하지 않는다.
  누락된 값을 추정해 채우지 않는다.
- `초기 공략 후보`, `운영 가설 점수`로 표시하며 네이버 공식 점수, 상위 노출 확률,
  1페이지 진입 보장이라고 표현하지 않는다.
- 상품명·스토어명·카테고리·속성·태그의 실제 등록값을 보존한 뒤 키워드가 어느
  필드에서 뒷받침되는지 비교한다.
- 검색 결과 표본을 기록할 때 기준 키워드, 확인 시각, 지면(가격비교/N+스토어), 기기,
  로그인·개인화 여부와 표본 수를 함께 저장한다.
- 현재 성장상품관리에서는 사용자가 직접 입력한 순위 또는 사용자가 버튼을 눌러
  Chrome 확장 프로그램이 가격비교 PC 공개 화면에서 관측한 순위만 실제 순위 이력으로
  저장한다. 예약·백그라운드 자동 수집이나 추정 순위로 표시하지 않는다.
- Chrome 확장 조회는 광고 표시 상품을 제외하고 최대 100위까지만 확인한다. CAPTCHA,
  접근 제한 또는 상품 카드 식별 실패가 발생하면 순위를 만들지 않고 차단·실패 상태를
  기록한다.
- 최근 7일·30일 판매 수량은 스마트스토어 주문 API에서 실제 결제된 상품 주문의
  잔여수량을 집계하고 취소·반품·미결제 주문은 제외한다. 이 값은 인기도 배점으로
  환산하지 않고 상품별 판매 반응을 고르는 근거로만 사용한다.

## 추가로 필요한 사용자 데이터

- 스토어명
- 상품별 실제 네이버 카테고리
- 상품별 등록 속성 이름과 값
- 상품별 검색 태그
- 키워드별 실제 순위와 확인 시각
- 가능하면 클릭 수, 판매량, 구매평 수와 품절 기간

이 데이터가 없으면 검색량 기반 초기 공략 표시는 가능하지만 필드별 적합도 분석이나
인기도 점수 계산은 실행하지 않는다.
